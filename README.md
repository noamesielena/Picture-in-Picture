# Picture-in-Picture Web Application

A lightweight web utility built with JavaScript that allows users to share their screen or camera feed and float it in a persistent Picture-in-Picture (PiP) window using native browser APIs.

## Features
- Screen & Media Capture: Prompts the user to select a media stream (screen share or webcam).
- Floating Window: Keeps the video visible on top of other windows using the native Picture-in-Picture API.
- Responsive Controls: Simple start and stop toggle mechanisms.

## Built With
- HTML5 (<video> elements and structure)
- CSS3 (Styling and layout containers)
- JavaScript (ES6+) (Async/Await functions and Web APIs)

## How to Run It
1. Open the project folder.
2. Open index.html in any modern browser that supports the Picture-in-Picture API (Chrome, Edge, Opera, etc.).
3. Click the START button, choose your display or window source, and activate PiP mode
